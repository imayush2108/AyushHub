## Brand & Style
The design system pairs executive-grade digital precision with the kinetic depth of high-end entertainment platforms. Designed for discerning tech operators, media curators, and luxury digital platforms, the interface communicates restrained authority, technical mastery, and deliberate sophistication. 

The aesthetic is built on a refined convergence of Dark Minimalism and Precision Glassmorphism. Rather than relying on loud neons or aggressive gradients, visual gravity is established through deep obsidian surfaces, structural 1-pixel micro-borders, controlled radial luminescence, and crisp, editorial typographic hierarchy. Every interaction feels deliberate, weighted, and engineered.

## Colors
The color palette relies on deep obsidian canvases punctuated by electric cobalt and twilight indigo, grounded with platinum typographic tones and calibrated ambient accents.

- **Foundational Surfaces**:
  - `Canvas / Onyx Base`: `#0b0f17` (Deepest viewport backdrop)
  - `Surface / Slate Elevated`: `#111827` (Layered cards, navigation frames)
  - `Surface / Obsidian Tonal`: `#1f2937` (Interactive modules, active states, popovers)
  - `Surface / Glass Highlight`: `rgba(255, 255, 255, 0.03)` to `rgba(255, 255, 255, 0.07)`

- **Accent Colors**:
  - `Primary / Sapphire Core`: `#2563eb` (Authoritative action items, primary toggles)
  - `Primary Glow / Cobalt Light`: `#3b82f6` (Hover states, focused borders, subtle radial glows)
  - `Secondary / Twilight Violet`: `#6366f1` (Supplemental visual accents, metadata badges)
  - `Tertiary / Soft Emerald`: `#10b981` (Success states, live activity pulses)
  - `Warning / Muted Amber Gold`: `#f59e0b` (Alerts, premium status tags, spotlight markers)

- **Typography & Structural Neutrals**:
  - `Text / Platinum Primary`: `#f9fafb` (Headlines, primary values)
  - `Text / Silver Secondary`: `#e5e7eb` (Subheads, active controls)
  - `Text / Titanium Muted`: `#9ca3af` (Body copy, captions, structural metadata)
  - `Text / Subtle Placeholder`: `#4b5563` (Disabled states, input placeholders)
  - `Stroke / Micro-Border`: `rgba(255, 255, 255, 0.08)` (Neutral component outlines)
  - `Stroke / Highlight Active`: `rgba(59, 130, 246, 0.35)` (Focused component outlines)

## Typography
Typographic rhythm balances architectural geometry and crystalline legibility. 

- **Display & Headlines (`Outfit`)**: Delivers geometric polish with subtle luxury nuances. Letter-spacing remains tightened on larger headings to reinforce cohesive visual weight.
- **Body & Controls (`Plus Jakarta Sans`)**: Provides open counters, balanced horizontal spacing, and high optical legibility across dense dashboard modules and dark interfaces.
- **Technical & Micro Metadata (`JetBrains Mono`)**: Reserved for timestamps, status values, media metrics, tickers, and token markers to introduce engineered precision. All monospace labels use uppercase transforms with wide letter-spacing.

## Layout & Spacing
The layout uses an adaptive 12-column grid system paired with strict 8pt base spatial intervals:

- **Desktop (1200px+)**: 12 columns, 2.5rem outer canvas margins, 1.5rem gutters. Maximum container width capped at 1440px for editorial comfort.
- **Tablet (768px - 1199px)**: 8 columns, 2rem margins, 1.25rem gutters. Complex dual-pane content folds down to dominant primary content with modular drawers.
- **Mobile (<768px)**: 4 columns, 1.25rem outer margins, 1rem gutters. Grids collapse into vertical stacks with horizontal edge-to-edge carousels for media objects.

Spacing follows structural grouping rules:
- `space-xs` (4px) and `space-sm` (8px) govern tight component-level lockups (chips, icons, micro-labels).
- `space-md` (16px) defines standard intra-card padding and element stacks.
- `space-lg` (24px) separates card sections, input groups, and nested components.
- `space-xl` (40px) manages vertical intervals between major content sections.

## Elevation & Depth
Elevation is achieved using translucent layering, physical micro-borders, and diffuse ambient back-lighting rather than drop shadows.

1. **Backdrop Canvas (`Level 0`)**: Solid `#0b0f17`. Supports contextual atmospheric radial glows (e.g., `radial-gradient(circle at 50% 0%, rgba(37, 99, 235, 0.08) 0%, transparent 70%)`).
2. **Elevated Panels (`Level 1`)**: `#111827` rendered at 80% opacity with `backdrop-filter: blur(16px)`. Framed by a 1px solid stroke of `rgba(255, 255, 255, 0.07)`.
3. **Floating Overlays & Menus (`Level 2`)**: `#1f2937` at 90% opacity with `backdrop-filter: blur(24px)`. Rimmed by a dual-edge treatment: a top border highlight of `rgba(255, 255, 255, 0.12)` and a soft ambient shadow (`0 20px 40px -15px rgba(0, 0, 0, 0.65)`).
4. **Focused & Active States (`Level 3`)**: Interactive surfaces gain an interior glow (`inset 0 1px 0 0 rgba(255, 255, 255, 0.2)`) paired with a dynamic outer sapphire luminescence (`0 0 24px -4px rgba(37, 99, 235, 0.35)`).

## Shapes
A roundedness factor of `2` anchors the system in an intentional modern aesthetic. 

- **Micro Controls & Chips**: 0.375rem (`6px`) to 0.5rem (`8px`) border radius. Keeps compact tools sharp and precise.
- **Buttons & Form Fields**: 0.5rem (`8px`) border radius (`rounded-md`).
- **Cards, Modals & Drawers**: 1rem (`16px`) radius (`rounded-lg`). Creates structured separation without playful distortion.
- **Hero Banners & Feature Units**: 1.5rem (`24px`) radius (`rounded-xl`). Used for full-bleed promotional displays and primary media modules.

## Components

### Buttons
- **Primary Action**: Gradient fill from `#2563eb` to `#1d4ed8` with a subtle top edge highlight (`1px inset rgba(255, 255, 255, 0.2)`). Platinum text (`#f9fafb`), 0.5rem border radius, height: 44px (desktop) / 48px (mobile). Hover triggers a cobalt ambient blur (`box-shadow: 0 0 20px rgba(37, 99, 235, 0.4)`).
- **Secondary / Ghost**: Background in `rgba(255, 255, 255, 0.03)` with a 1px micro-border `rgba(255, 255, 255, 0.08)`. Hover transitions surface to `rgba(255, 255, 255, 0.08)` and border to `rgba(255, 255, 255, 0.2)`.

### Cards & Media Shells
- Cards use `#111827` at 70% opacity, `backdrop-filter: blur(20px)`, and a continuous 1px border of `rgba(255, 255, 255, 0.07)`.
- Media frames utilize a 16:9 or 2:1 aspect ratio with an interior gradient scrim (`linear-gradient(to top, #0b0f17 0%, transparent 60%)`) to ensure consistent typographic readability across varied imagery.

### Form Inputs & Selectors
- Surface: `#0b0f17` inset layer surrounded by `rgba(255, 255, 255, 0.1)` 1px border.
- Text: `#f9fafb` body typography with `#4b5563` placeholders.
- Focus State: Border transitions to `#3b82f6` with a delicate halo: `box-shadow: 0 0 0 3px rgba(59, 130, 246, 0.15)`.

### Chips & Status Badges
- Built with `label-mono` typography. 
- Live indicator: Soft Emerald (`#10b981`) text with `rgba(16, 185, 129, 0.1)` background and an active glowing beacon dot.
- Category pills: Deep indigo background (`rgba(99, 102, 241, 0.12)`), `#6366f1` border at 30%, and platinum text.

### Checkboxes & Radios
- Size: 18x18px. Rest state: `rgba(255, 255, 255, 0.05)` fill with `rgba(255, 255, 255, 0.2)` border.
- Selected state: Primary Sapphire fill (`#2563eb`) displaying a crisp, micro-white checkmark or circular radio core with a soft sapphire aura.

### Lists & Navigation Rails
- Rows alternate with `rgba(255, 255, 255, 0.01)` striping on dense tables.
- List items feature a 1px baseline border of `rgba(255, 255, 255, 0.04)`. Hover initiates a gentle lateral shift (+2px X-axis) accompanied by a subtle sapphire left-rail indicator.
